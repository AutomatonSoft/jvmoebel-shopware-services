# Тесты роутов AR-моделей

Тесты router-слоя проверяют API-контракт и основные HTTP-сценарии работы с AR-моделями через реальные HTTP-запросы к FastAPI-приложению.

## Что тестируется

1. **Получение несуществующей модели**
   - выполняется `GET /api/v1/ar/models/{sku}`;
   - если модели нет, возвращается `200`;
   - возвращается `available: false`.

2. **Публичный доступ к получению модели**
   - выполняется `GET /api/v1/ar/models/{sku}`;
   - проверяется, что эндпоинт доступен без авторизации;
   - ожидается `200 OK`.

3. **Создание модели**
   - выполняется `POST /api/v1/ar/models/{sku}`;
   - передаются файл и размеры товара;
   - ожидается `201 Created`;
   - проверяются SKU, формат, URL файла и размеры;
   - размеры автоматически конвертируются из сантиметров в метры.

4. **Создание модели без аутентификации**
   - выполняется `POST /api/v1/ar/models/{sku}` без заголовков авторизации;
   - ожидается `401 Unauthorized`.

5. **Создание модели с невалидным токеном**
   - выполняется `POST /api/v1/ar/models/{sku}` с невалидным токеном;
   - ожидается `401 Unauthorized`.

6. **Получение существующей модели**
   - сначала создаётся модель;
   - затем выполняется `GET /api/v1/ar/models/{sku}`;
   - проверяется, что API возвращает данные именно этой модели.

7. **Модель другого SKU не возвращается**
   - создаётся модель для одного SKU;
   - выполняется запрос с другим SKU;
   - возвращается `available: false`.

8. **Получение файла модели**
   - создаётся модель;
   - выполняется `GET /api/v1/ar/models/{sku}/file`;
   - проверяется `200`;
   - проверяется содержимое возвращённого файла.

9. **Публичный доступ к получению файла модели**
   - создаётся модель;
   - выполняется `GET /api/v1/ar/models/{sku}/file` без авторизации;
   - проверяется `200 OK`.

10. **Получение отсутствующего файла**
    - выполняется запрос файла для неизвестного SKU;
    - ожидается `404 Not Found`.

11. **Замена модели**
    - создаётся первоначальная модель;
    - выполняется `PUT /api/v1/ar/models/{sku}`;
    - проверяются обновлённые размеры и данные модели.

12. **Замена модели без аутентификации**
    - выполняется `PUT /api/v1/ar/models/{sku}` без заголовков авторизации;
    - ожидается `401 Unauthorized`.

13. **Замена модели с невалидным токеном**
    - выполняется `PUT /api/v1/ar/models/{sku}` с невалидным токеном;
    - ожидается `401 Unauthorized`.

14. **Замена несуществующей модели**
    - выполняется `PUT` для неизвестного SKU;
    - ожидается `404 Not Found`.

15. **Изменение статуса модели**
    - выполняется `PATCH /api/v1/ar/models/{sku}/status`;
    - статус изменяется на `not_active`;
    - проверяется ответ API.

16. **Изменение статуса модели без аутентификации**
    - выполняется `PATCH /api/v1/ar/models/{sku}/status` без заголовков авторизации;
    - ожидается `401 Unauthorized`.

17. **Изменение статуса модели с невалидным токеном**
    - выполняется `PATCH /api/v1/ar/models/{sku}/status` с невалидным токеном;
    - ожидается `401 Unauthorized`.

18. **Отключённая модель недоступна покупателю**
    - модель переводится в `not_active`;
    - выполняется `GET /api/v1/ar/models/{sku}`;
    - API возвращает `200` и `available: false`.

19. **Удаление модели**
    - создаётся модель;
    - выполняется `DELETE /api/v1/ar/models/{sku}`;
    - ожидается `204 No Content`;
    - после удаления `GET` возвращает `available: false`.

20. **Удаление модели без аутентификации**
    - выполняется `DELETE /api/v1/ar/models/{sku}` без заголовков авторизации;
    - ожидается `401 Unauthorized`.

21. **Удаление модели с невалидным токеном**
    - выполняется `DELETE /api/v1/ar/models/{sku}` с невалидным токеном;
    - ожидается `401 Unauthorized`.

22. **Удаление несуществующей модели**
    - выполняется `DELETE` для неизвестного SKU;
    - ожидается `404 Not Found`.

## Как выполняются тесты

Тесты не запускают отдельный HTTP-сервер.

Используется `httpx.AsyncClient` с `ASGITransport`, который передаёт HTTP-запросы непосредственно в FastAPI-приложение.

```text
AsyncClient
    ↓
ASGITransport
    ↓
FastAPI
    ↓
Router
    ↓
Service
    ↓
Test PostgreSQL
